# janiota-a

sixTone紹介サイトのリポジトリです。

## 概要

このリポジトリは、sixTone紹介サイトの構築・管理を目的としています。
現在は初期段階で、サイトの実装はこれから追加されていく予定です。

## Claude Code連携

このリポジトリでは [Claude Code GitHub Action](https://github.com/anthropics/claude-code-action) を利用しています。
Issueやプルリクエストのコメントで `@claude` にメンションすると、Claudeが内容を解析し、質問への回答やコード変更などを自動で行います。

設定ファイルは [`.github/workflows/claude.yml`](.github/workflows/claude.yml) にあります。
